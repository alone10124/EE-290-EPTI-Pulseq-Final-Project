<h2>Library for EPTI Raw Data Processing, Reconstruction, and Analysis</h2>

This package provides a set of functions for raw data handling, image reconstruction, and data preprocessing for Echo Planar Time-resolved Imaging (EPTI). It is designed to support researchers working with EPTI acquisition across different field strengths and applications/contrasts, offering functions for k-space data processing, calibration, phase correction, subspace reconstruction, and parameter fitting.

The library includes:  
(1) Raw Data Processing: Functions for reading and handling EPTI raw data, including constructing trajectory patterns and applying standard phase correction.  
(2) Image Reconstruction: Support for single-shot and multi-shot EPTI reconstruction with parallel imaging, subspace reconstruction, and phase updating.  
(3) Preprocessing and Analysis: Tools for generating time-resolved echo images, write data headers, quantitative T2/T2* fitting, and preparing data for subsequent fMRI or other analysis.  

This package serves as a foundation for EPTI data analysis and can be adapted or extended for custom reconstruction pipelines.
